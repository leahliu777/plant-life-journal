# 植物生活记录

这是一个手机优先的静态 Web App，用来记录络石、泼墨石斛、台湾香水柠檬、薄荷和蓝雪花的浇水、施肥、移盆观察与日常日志。

## 使用方式

直接打开 `index.html` 即可使用。手机上可以把这个页面添加到主屏幕，当成轻量 App 使用。

如果要启用 PWA 离线缓存和浏览器通知，建议用本地服务器或部署到任意静态站点服务上，例如 GitHub Pages、Netlify、Vercel 或自己的 NAS。

## 功能

- 今日到期任务
- 植物档案和间隔调整
- 月历计划与当天日志
- 热天模式
- 深圳实时天气和空气质量
- 本机浏览器数据保存
- 猫咪安全提示

浏览器通知只有在应用打开或被系统允许后台保活时才可靠。真正系统级定时推送需要原生 App、微信小程序订阅消息或后端推送服务。

## 数据来源

天气与空气质量使用 Open-Meteo 免费 API。天气接口提供深圳坐标的当前温度、相对湿度；空气质量接口提供 US AQI，并在页面中转成「优 / 良好 / 轻度 / 中度 / 较差」。

## Bark 推送参考

项目里有一份 `care-config.json`，给外部 agent 或定时任务读取。推荐方案是：

1. GitHub Pages 托管这个静态 App。
2. 另一个 agent 每天早上读取 `care-config.json`。
3. 根据植物间隔、到家日期、上次记录日期计算今日任务。
4. 调用 Bark URL 推送到手机。

Bark URL 通常类似：

```text
https://api.day.app/{BARK_KEY}/植物生活记录/今天有 2 个养护任务：薄荷浇水、蓝雪花检查盆土湿度
```

不要把 Bark key 写进公开仓库；建议放在运行推送 agent 的环境变量里。
